Desktop Snow для Windows 10 и 11

Выберите x64 для ПК с Intel или AMD. На ПК с Windows on Arm используйте ARM64.
Распакуйте архив в обычную папку и запустите DesktopSnow.exe.
Настройки открываются кликом по снежинке в области уведомлений рядом с часами.
Если значок скрыт, откройте список скрытых значков стрелкой рядом с часами.

В меню доступны интенсивность, порывы ветра, скорость таяния, сугробы,
пауза и очистка. Снег ложится на окна, панель задач и нижний край экрана.
В полноэкранных окнах остаётся редкий снегопад.
Автозапуск включается пунктом «Запускать при входе». При перемещении
исполняемого файла выключите и снова включите автозапуск из новой папки.
Для остановки выберите «Завершить Desktop Snow».

Сборка сделана на macOS. Проверены симуляция и формат исполняемых файлов.
Интерфейс и отрисовку на Windows ещё предстоит проверить.
Интеграции с виджетами Windows в этой версии нет.
