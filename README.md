# Desktop Snow — Pixel Edition

Нативный снег для macOS 13+, Swift / AppKit. Без сторонних зависимостей.

## Запуск

Откройте `dist/Desktop Snow.app`. Управление — через снежинку в строке меню.
Приложение не появляется в Dock и пропускает клики к окнам под снегом.

В меню доступны интенсивность, скорость таяния, случайный ветер, накопление,
пауза, очистка снега и запуск при входе. Настройки сохраняются между запусками.
Пауза замораживает всю симуляцию, включая таяние.

Для точного накопления на Dock выберите «Разрешить точное определение Dock…»
и включите Desktop Snow в «Системные настройки → Конфиденциальность и безопасность → Универсальный доступ».
Если macOS потребует, перезапустите приложение. Для обычных окон разрешение не требуется.
Без этого разрешения сугробы на Dock работают с приблизительными границами; меню явно показывает такой режим.
Приложение читает только геометрию окон и Dock: оно не захватывает изображение экрана,
не записывает нажатия и не использует сеть.

Автозапуск включается пунктом «Запускать при входе». Если macOS запросит
подтверждение, разрешите его в настройках объектов входа. После включения не
перемещайте приложение: служба привязана к его расположению.

## Поведение

- Пиксельные хлопья двух размеров и редкие крупные снежинки-крестики.
- Плавные случайные порывы ветра раз в 5–14 секунд. Во время ветра добавляется приток с наветренного бокового края на верхних 88% экрана; его интенсивность зависит от скорости ветра. Общая граница двух мониторов не создаёт двойной поток.
- Нижний сугроб рисуется отдельным слоем позади окон и системного Dock: он не закрывает значки даже без доступа к геометрии Dock.
- Сугроб рисуется замкнутой полосой вдоль контура окна: толщина откладывается по нормали к дуге и плавно сходит к нулю у вертикальных касательных. Отдельных вертикальных столбиков и обрезанного белого кончика нет. Столкновения частиц используют ту же геометрию, что и отрисовка.
- Обычные окна используют скруглённый контур для столкновений, отсечения и снега на краях. Радиус по умолчанию 26 пунктов, регулируется в меню; приложения с собственным оформлением могут иметь другой радиус.
- Сугробы на открытых верхних краях окон, Dock и виджетов рабочего стола, а также у нижнего края мониторов. Виджеты определяются по отдельным окнам Notification Center на слое рабочего стола; прозрачный отступ контейнера 8 пунктов исключён из поверхности накопления.
- CleanMyMac исключён из накопления: версия X, новые версии и помощники по идентификаторам `com.macpaw.CleanMyMac*`, с запасной проверкой имени. Окна остаются препятствиями для чужих сугробов. При исключении старый сугроб удаляется без осыпания. Quick Look и плавающие панели перекрывают сугробы задних окон и падающие частицы.
- Область системного меню и значков состояния защищена от всей отрисовки снега, включая края крупных снежинок. Отступ рассчитывается отдельно для каждого монитора с учётом высоты меню и выреза. Сугробы сохраняются в симуляции; их часть внутри защищённой области не рисуется.
- Полноэкранные окна определяются с учётом полосы меню/выреза: прямые края, без искусственного скругления. На таком экране Dock не создаёт поверхность накопления, его сугроб хранится скрытым до возвращения. В полноэкранном режиме и Fill шапка окна не собирает снег. Внутри окна видны примерно 5% снежинок из верхнего и бокового потоков. Fill определяется по границам рабочей области и сохраняет сугроб на Dock.
- При перемещении и изменении размеров окна снег частично осыпается.
- При закрытии окна остатки снега падают вниз.
- У Dock используется одна поверхность со скруглёнными краями. При доступе к геометрии AX/CG применяется поправка верхнего отступа; без доступа используется приблизительная полка по положению Dock, резерву рабочей области, размеру и количеству значков. Минимизированные окна не всегда отражаются в этом расчёте. Меню показывает, определены границы или рассчитаны приблизительно.
- Переполненный сугроб на Dock осыпается вниз; частицы ускоряются и не прилипают обратно к Dock.
- «Посадка на Dock: выше → ниже» позволяет подстроить границу под внешний вид macOS (по умолчанию отступ 6 пунктов). Геометрия стеклянного фона Dock не предоставляется публичным API; поправка к контейнеру приблизительная.
- Снег постепенно тает полностью, в том числе по краям сугробов.
- Смена рабочего стола и переходы через полноэкранные приложения сохраняют частицы и сугробы. При смене пространства обновляются видимые поверхности. Во время ручной паузы частицы сохраняют координаты, а сугробы скрытых окон сохраняются до их возвращения. Повторные уведомления об экранах с прежними размерами не очищают снег.
- Нагрузка ограничена 3500 частицами, частота анимации — 30 кадров/с.

## Сборка и проверки

```sh
./scripts/build.sh
.build/release/DesktopSnow --self-test
.build/release/DesktopSnow --render-demo preview.png
.build/release/DesktopSnow --render-corners corners-preview.png
.build/release/DesktopSnow --diagnostics
.build/release/DesktopSnow --probe-widgets
```

`--self-test` проверяет несколько экранов, перекрытие окон, столкновения,
накопление, осыпание, удаление окон, очистку, полное таяние и длительную симуляцию. Дополнительно проверяются поправка Dock, скругления, переполнение, падение снега без повторного прилипания, сохранение скрытых сугробов, повторные уведомления экранов, боковая генерация при обоих направлениях ветра и отсутствие боковой генерации в штиль.
`runtime-status.json` содержит текущий источник границ Dock, видимость его поверхности, области полноэкранных окон, наличие разрешения, число частиц и накопленный снег на Dock. Он обновляется работающим приложением и помогает отличить реальную проверку от синтетической.

`corners-preview.png` — сравнение концов сугробов для радиусов 10, 20, 26 и 36 пунктов.

`preview.png` — синтетическая демонстрация рендера, не снимок рабочего стола.

Сборка подписывается локальной ad-hoc подписью с постоянным designated requirement по идентификатору приложения, чтобы системные разрешения могли сохраняться при обновлениях. После перехода со старой подписи может потребоваться один раз выключить и включить разрешение «Универсальный доступ». Для распространения на другие
Mac нужны подпись Developer ID и notarization.

## Ограничения

Отслеживание окон опрашивает публичный CGWindowListCopyWindowInfo, а не внедряется
в приложения. При очень быстром движении возможна задержка около 50 мс.
Окна защищённого системного интерфейса и эксклюзивный полноэкранный режим могут
перекрывать снег. Боковой Dock собирает снег на своём верхнем коротком краю.
Для нескольких мониторов есть автоматическая поддержка координат и отдельных
прозрачных слоёв; физическая проверка на нескольких дисплеях ещё не проводилась.
Автозапуск требует проверки после реального повторного входа в macOS.

## Архитектура

- `SnowEngine.swift`: частицы, геометрия столкновений и сугробы в координатах Quartz.
- `App.swift`: прозрачные панели для экранов, пиксельный рендер, меню и автозапуск.
- `DockResolver.swift`: границы Dock через AX/CG и приблизительный резервный расчёт. Скрытая за экраном AX-полка не заменяется воображаемой видимой.
- `SnowContour.swift`: замкнутый контур сугроба, белая кромка и общая с рендером поверхность столкновений.
- `WindowRules.swift`: определение настольных виджетов и исключения приложений.
- `ScreenLayout.swift`: полноэкранная геометрия с учётом верхнего системного отступа.
- `main.swift`: точка входа, проверки и синтетическое превью.
- `scripts/build.sh`: release-сборка и упаковка .app.

Используются публичные API Apple:
[Quartz Window Services](https://developer.apple.com/documentation/coregraphics/quartz-window-services),
[SMAppService](https://developer.apple.com/documentation/servicemanagement/smappservice),
[NSWindow](https://developer.apple.com/documentation/appkit/nswindow).
